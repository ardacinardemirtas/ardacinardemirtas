### Hi, I'm Arda 👋

I'm an MSc student at ETH Zürich. I like problems where geometry, learning, and the physical world meet — which usually means I end up somewhere between 3D vision, generative modeling, and robotics.

---

#### What I'm thinking about lately

Event cameras are a beautiful sensor and I think we're still figuring out what to do with them. Right now I'm exploring whether large pretrained 4D reconstructors can be adapted to event input without ground-truth labels — the surprising answer so far is "almost, for free."

I'm also drawn to the idea that modern SfM pipelines are quietly becoming the substrate for everything else in 3D — so I've been spending time inside COLMAP, teaching it to handle 360° visual-inertial rigs for a construction-site SLAM challenge.

And on the side, a robot arm is learning to type on a keyboard. It's worse at it than I am, for now.
